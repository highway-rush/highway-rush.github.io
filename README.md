# Highway Rush 🏎️

Бесконечная 3D-гонка по шоссе с трафиком прямо в браузере. Работает на компьютере и на телефонах (Android и iPhone) по одной ссылке, без установки.

Сделано на **HTML + CSS + JavaScript (ES-модули) + [Three.js](https://threejs.org/)** (подключается из CDN). Все 3D-модели собраны в коде из простых фигур, все звуки синтезируются через Web Audio API — внешних картинок, моделей и аудиофайлов нет.

## Что есть в игре

- **4 режима:**
  - **Бесконечный** — одностороннее шоссе, 4 полосы;
  - **Встречка** — по 2 полосы в каждую сторону, на встречке очков в 2 раза больше плюс бонус за время на встречной полосе;
  - **На время** — 60 секунд, каждые 1000 м чекпоинт добавляет время;
  - **Полиция** — вы на полицейской машине с мигалкой и сиреной: догоните нарушителя и продержитесь рядом 2 секунды. Машины впереди уступают дорогу.
- **5 локаций:** Шоссе, Снег (машина скользит), Ночной город, Дождь, Степь Казахстана (юрты, ЛЭП, закат).
- **Гараж:** 8 машин с характеристиками (скорость, разгон, управление, торможение), покупка за монеты, перекраска кузова.
- **Очки** начисляются только быстрее 50 км/ч, за «близкий обгон» — бонус и комбо-множитель. Монеты — 10 % от очков.
- **Рекорды:** топ-10 для каждого режима.
- **Настройки:** громкость музыки и эффектов, качество графики, руль наклоном телефона, язык.
- **3 языка:** русский, қазақша, English.
- Всё сохраняется в браузере (localStorage).

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Руль | ← / → или A / D | кнопки ◀ ▶ слева (или наклон телефона) |
| Газ | ↑ или W | кнопка «Газ» справа |
| Тормоз | ↓, S или Пробел | кнопка «Тормоз» справа |
| Гудок | H | кнопка 📯 |
| Пауза | Esc или P | кнопка ❚❚ |

На телефоне держите его горизонтально. Можно нажимать руль и газ одновременно.

## Как запустить на компьютере

Игру нельзя открыть двойным кликом по `index.html`: браузер запрещает загружать JS-модули с адреса `file://`. Нужен маленький локальный веб-сервер.

1. Откройте Терминал в папке игры.
2. Выполните команду (Python есть на macOS и Linux; на Windows установите его с python.org):

   ```bash
   python3 -m http.server 8080
   ```

3. Откройте в браузере адрес **http://localhost:8080**

Остановить сервер — `Ctrl + C` в Терминале. Для работы игре нужен интернет (Three.js загружается из CDN).

## Как выложить в интернет (GitHub Pages)

1. Создайте на github.com новый **публичный** репозиторий, например `highway-rush`.
2. Загрузите в него все файлы проекта (через `git push` или кнопкой «Add file → Upload files»).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты игра будет доступна по ссылке `https://ВАШ-ЛОГИН.github.io/highway-rush/`.

## Структура проекта

```
index.html        — страница и все экраны интерфейса
css/style.css     — стили
js/main.js        — запуск, рендерер, игровой цикл
js/game.js        — логика заезда: очки, комбо, столкновения, камера, гараж-превью
js/player.js      — машина игрока и её физика
js/traffic.js     — трафик: полосы, перестроения, поворотники, уступание полиции
js/world.js       — бесконечная дорога (переиспользуемые участки), небо, свет, погода
js/locations.js   — настройки и декор пяти локаций
js/models.js      — все 3D-модели из простых фигур
js/modes.js       — четыре режима игры
js/cars.js        — машины гаража и их характеристики
js/ui.js          — экраны, HUD, гараж, рекорды, настройки
js/audio.js       — синтезированные звуки и музыка
js/input.js       — клавиатура, сенсорные кнопки, наклон
js/storage.js     — сохранение прогресса
js/i18n.js        — все тексты на трёх языках
```
