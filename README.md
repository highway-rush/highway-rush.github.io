# Highway Rush 🏎️

Бесконечная 3D-гонка по шоссе с трафиком прямо в браузере. Работает на компьютере и на телефонах (Android и iPhone) по одной ссылке, без установки.

Сделано на **HTML + CSS + JavaScript (ES-модули) + [Three.js](https://threejs.org/)** (подключается из CDN). Все 3D-модели собраны в коде из простых фигур, все звуки синтезируются через Web Audio API — внешних картинок, моделей и аудиофайлов нет.

## Что есть в игре

- **4 режима:**
  - **Бесконечный** — одностороннее шоссе, 4 полосы;
  - **Встречка** — по 2 полосы в каждую сторону, на встречке очков в 2 раза больше плюс бонус за время на встречной полосе;
  - **На время** — 60 секунд, каждые 1000 м чекпоинт добавляет время;
  - **Полиция** — вы на полицейской машине с мигалкой и сиреной: догоните нарушителя и продержитесь рядом 2 секунды. Машины впереди уступают дорогу.
- **5 локаций:** Шоссе, Снег (машина скользит), Ночной город, Дождь, Степь Казахстана (юрты, ЛЭП, закат).
- **Прыжок:** машина подпрыгивает выше грузовика и перелетает через машину впереди. Перезарядка 3 секунды (видна кругом на кнопке). Бонус «Прыжок через машину!» за каждую машину внизу. Приземлиться на крышу — авария.
- **Полёт:** раскрываются крылья, сзади включается реактивное пламя, машина поднимается выше трафика. Полной шкалы энергии хватает примерно на 7 секунд, очки в полёте ×1.5. Энергия копится за обгоны впритык, прыжки через машины и светящиеся зелёные **батарейки** на дороге. Когда энергия кончается, машина плавно планирует вниз.
- **Препятствия в воздухе** (только в полёте): вертолёты, дроны, стаи птиц и эстакады с проёмом, в который надо пролететь. Со временем их становится больше.
- **Гараж:** 8 машин с характеристиками (скорость, разгон, управление, торможение), покупка за монеты, перекраска кузова. Стартовая машина — розовая.
- **Очки** начисляются только быстрее 50 км/ч, за «близкий обгон» — бонус и комбо-множитель. Монеты — 10 % от очков.
- **Рекорды:** топ-10 для каждого режима.
- **Настройки:** громкость музыки и эффектов, качество графики, руль наклоном телефона, язык.
- **Онлайн-мультиплеер** до 4 игроков: комнаты по коду или ссылке, общая трасса 3 / 5 / 10 км, толкание машин, финиш, реванш. Подробнее — ниже.
- **3 языка:** русский, қазақша, English.
- Всё сохраняется в браузере (localStorage).

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Руль | ← / → или A / D | кнопки ◀ ▶ слева (или наклон телефона) |
| Газ | ↑ или W | кнопка «Газ» справа |
| Тормоз | ↓ или S | кнопка «Тормоз» справа |
| Прыжок | Пробел | кнопка «Прыжок» (▲) справа |
| Полёт (вкл/выкл) | F или Shift | кнопка «Полёт» (✈) справа |
| Гудок | H | кнопка 📯 |
| Пауза | Esc или P | кнопка ❚❚ |

На телефоне держите его горизонтально. Можно нажимать несколько кнопок одновременно (руль, газ, прыжок). При первом запуске игра сама подскажет, как прыгать и летать.

## Онлайн: как играть

1. В главном меню нажмите **«Онлайн»** и введите ник (до 12 символов; он хранится только на вашем устройстве).
2. **«Создать комнату»** — появится код из 5 символов, например `KZ7F2`. Нажмите **«Копировать код»** или **«Отправить ссылку»** и пришлите другу. Ссылка вида `https://…/?room=KZ7F2` сразу открывает вход в эту комнату.
3. Друг нажимает **«Онлайн»**, вводит код и **«Войти»** (или просто открывает ссылку).
4. В комнате до 4 игроков. Создатель комнаты (хост, 👑) выбирает локацию и длину трассы. Все нажимают **«Я готов»**, хост — **«Старт»**.
5. Отсчёт 3-2-1-СТАРТ идёт одновременно у всех. Цель — первым доехать до финишной арки с клетчатым флагом.

Правила гонки:
- Трафик, батарейки и препятствия в воздухе у всех одинаковые.
- Авария — это не конец, а штраф: машина мигает и стоит ~2 секунды, потом снова едет; ещё 2 секунды она полупрозрачная и неуязвимая.
- Машины игроков толкают друг друга (грузовик толкает сильнее). Толчок от игрока — не авария. В воздухе игроки не сталкиваются.
- Прыжок и полёт работают; у соперников видно прыжки и крылья.
- Сверху: ваше место (например, 2/4), полоса трассы с точками всех игроков и сколько осталось до финиша. Стрелки по краям экрана показывают соперников позади или далеко впереди.
- После финиша первого игрока остальным даётся 30 секунд, потом места считаются по пройденной дистанции.
- Монеты: 1 место — 300, 2 — 180, 3 — 120, 4 — 80 (для трассы 5 км; для 3 км меньше, для 10 км больше). Кнопка **«Реванш»** — новая гонка в той же комнате, с новым трафиком.
- Если игрок вышел или у него пропал интернет больше чем на 15 секунд, он выбывает. Если вышел хост, хостом становится следующий игрок.

Одиночные режимы работают без интернета, как раньше. Онлайну нужен интернет и настроенный Firebase (см. «Настройка онлайна»).

## Как запустить на компьютере

Игру нельзя открыть двойным кликом по `index.html`: браузер запрещает загружать JS-модули с адреса `file://`. Нужен маленький локальный веб-сервер.

1. Откройте Терминал в папке игры.
2. Выполните команду (Python есть на macOS и Linux; на Windows установите его с python.org):

   ```bash
   python3 -m http.server 8080
   ```

3. Откройте в браузере адрес **http://localhost:8080**

Остановить сервер — `Ctrl + C` в Терминале. Для работы игре нужен интернет (Three.js загружается из CDN).

## Игра в интернете

Игра опубликована на GitHub Pages: **https://highway-rush.github.io/**

Как выложить новую версию после изменений (в Терминале, в папке игры):

```bash
git add .
git commit -m "Описание изменений"
git push
```

Через 1–2 минуты сайт обновится сам. Если в браузере видна старая версия, обновите страницу с очисткой кэша: `Cmd + Shift + R` (Mac) или `Ctrl + F5` (Windows).

## Настройка онлайна (один раз)

Онлайн работает через бесплатный **Firebase** (план Spark): Realtime Database + анонимный вход.

1. На [console.firebase.google.com](https://console.firebase.google.com) создайте проект.
2. **Build → Authentication → Sign-in method** → включите **Anonymous**.
3. **Build → Realtime Database → Create database**, регион **europe-west1 (Бельгия)**, режим **Locked mode**.
4. Вкладка **Rules** базы → вставьте всё содержимое файла `database.rules.json` → **Publish**.
5. **⚙ Project settings → Your apps → Web (</>)** → зарегистрируйте приложение → скопируйте объект `firebaseConfig` в файл `js/firebase-config.js`.
6. **Authentication → Settings → Authorized domains** → добавьте домен сайта (например, `highway-rush.github.io`). `localhost` там уже есть.

Значения в `firebase-config.js` не секретные (их всё равно видно в браузере). Защищают данные правила базы:
вход только анонимный, игрок пишет только своё состояние, размеры и типы данных проверяются, список комнат прочитать нельзя — только комнату, код которой знаешь.

Пустые комнаты удаляются сами: когда выходит последний игрок или у него пропадает интернет. Старые комнаты (старше 2 часов) удаляются при попытке в них войти.

### Проверка онлайна без Firebase

Для разработки есть локальный режим: откройте `http://localhost:8080/?net=local` в двух-трёх вкладках или окнах одного браузера — они играют друг с другом без интернета-сервера. Добавка `&lag=120` имитирует задержку сети 120 мс.
Анонимный вход у каждой вкладки свой, поэтому и с Firebase можно открыть игру в двух окнах и сыграть самому с собой.
Окна лучше ставить рядом: в свёрнутой или фоновой вкладке браузер останавливает игру, и через 15 секунд такой игрок выбывает.

### Как проверить онлайн с другом (компьютер + телефон)

1. Выложите обновление на GitHub Pages (см. «Игра в интернете») и подождите 1–2 минуты.
2. На компьютере откройте сайт, **«Онлайн»** → ник → **«Создать комнату»**.
3. Нажмите **«Копировать код»** или **«Отправить ссылку»** и отправьте другу (например, в WhatsApp/Telegram).
4. Друг открывает ссылку на телефоне (или сайт → **«Онлайн»** → код → **«Войти»**). Телефон лучше держать горизонтально.
5. Оба жмут **«Я готов»**, вы (хост) — **«Старт»**.

## Структура проекта

```
index.html        — страница и все экраны интерфейса
css/style.css     — стили
js/main.js        — запуск, рендерер, игровой цикл
js/game.js        — логика заезда: очки, комбо, столкновения, камера, гараж-превью, обучение
js/player.js      — машина игрока: физика, прыжок, полёт, пыль и тень
js/air.js         — воздушные препятствия и батарейки
js/traffic.js     — трафик: полосы, перестроения, поворотники, уступание полиции
js/world.js       — бесконечная дорога (переиспользуемые участки), небо, свет, погода
js/locations.js   — настройки и декор пяти локаций
js/models.js      — все 3D-модели из простых фигур (в том числе крылья и пламя)
js/modes.js       — четыре режима игры
js/cars.js        — машины гаража и их характеристики
js/ui.js          — экраны, HUD, гараж, рекорды, настройки
js/audio.js       — синтезированные звуки и музыка
js/input.js       — клавиатура, сенсорные кнопки, наклон
js/storage.js     — сохранение прогресса
js/i18n.js        — все тексты на трёх языках
js/firebase-config.js — настройки Firebase для онлайна (заполняются один раз)
js/net/backend.js     — подключение к Firebase (загружается только при входе в «Онлайн») и выбор локального режима
js/net/local-db.js    — локальная база для проверки онлайна во вкладках (?net=local)
js/net/room.js        — комнаты: создание, вход по коду, игроки, хост, выход
js/net/track.js       — общая трасса из seed: трафик (позиция = функция времени), препятствия, батарейки
js/net/prng.js        — детерминированный генератор случайных чисел
js/net/race.js        — онлайн-гонка: отсчёт, штрафы, толкание, финиш, монеты, HUD
js/net/race-views.js  — отрисовка трафика, препятствий, батареек, финишной арки
js/net/remote-car.js  — машины соперников: интерполяция, ник над машиной
js/net/online-ui.js   — экраны «Онлайн», лобби, результаты
js/net/nick.js        — проверка ника и фильтр грубых слов
database.rules.json   — правила безопасности базы Firebase
```
